# Sales Dashboard - Data Visualization

This project analyzes sales data across 4 cities and 5 products.

## Tools Used
- Python
- Matplotlib
- Pandas

## Key Insights
- Hyderabad has highest sales: 750
- Top selling product: Laptop

## Charts
1. City Wise Sales - Bar Chart
2. Product Wise Sales - Bar Chart
3. Price Share - Pie Chart
4. Price vs Sales - Scatter Plot
